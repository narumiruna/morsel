# Example document

This small document is bundled with Morsel. It does not use an account, an external service, or a share view.

## Reading Markdown

Morsel renders **headings**, lists, tables, and inline code such as `open_document()`.

1. Read the rendered document.
2. Select **Raw** to see its Markdown source.
3. Copy or download the Markdown with the document controls.

| Format | Example |
| --- | --- |
| Emphasis | *A short note* |
| Code | `const ready = true` |

> Share links can expire or have view limits. This example has neither.

```js
const message = "Ready to read"
console.log(message)
```
